- [ ] Abrir a **versão final com botões verdes** no Wokwi, instalar duas bibliotecas e compilar sem erros.
- [ ] Executar e confirmar T01 a T06 da tabela de testes do README (T07, se possível).
- [ ] Comprovar que cada botão alterna estado com um clique e que o LCD mostra as informações.
- [ ] Modificar manualmente o LDR ao modificar NPK, como exige o enunciado.
- [ ] Salvar capturas **reais** do circuito e dos estados da bomba na pasta `imagens/`.
- [ ] Descomentar a referência de imagem `imagens/circuito.png` no README após adicionar o arquivo.
- [ ] Adicionar link compartilhável do Wokwi no README.
- [ ] Preencher nomes, RMs e turma no README.
- [ ] Gravar vídeo próprio de até 5 minutos, subir ao YouTube como **Não listado** e inserir link no README.
- [ ] Conferir que o GitHub contém sketch.ino, diagram.json, libraries.txt, README.md, imagens e link do vídeo.
- [ ] Revisar os parâmetros didáticos e tornar a descrição autoral e fiel ao funcionamento observado.
- [ ] Enviar ao portal FIAP o arquivo/link correto e não alterar o GitHub após o prazo indicado.
